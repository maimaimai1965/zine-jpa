# database_zine 

Инсталяция схем *zine* и *zine02* (*zine02* - полный аналог *zine*).


### Installation steps

Для установки схемы *zine* нужно выполнить в этой папке в терминале команду:

$ .\_install_zine_with_env.bat

Для установки схемы *zine02* нужно выполнить в этой папке в терминале команду:

$ .\_install_zine02_with_env.bat

Установка схем выполняется в базе данных [MySQL 8](../../../../db/mysql/mysql8/README.md) 

### By default, the exposes the following ports:

* **3316**: [MySQL 8](../../../../db/mysql/mysql8/README.md)
  * Credential: (root/root)
  * Schema zine (zine/zine)
  * Schema zine02 (zine02/zine02)
